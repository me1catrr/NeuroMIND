# Figuras vectoriales: números complejos, fase y sincronización en EEG

Carpeta generada a partir de la infografía de referencia, creando ilustraciones nuevas y no recortes.

Contenido:
- 12 archivos SVG vectoriales editables.
- 12 archivos PDF vectoriales para incluir directamente en LaTeX.
- `latex_include_examples.tex` con ejemplos de inclusión.

Uso recomendado:
```latex
\usepackage{graphicx}
\includegraphics[width=0.9\linewidth]{complex_phase_eeg_vector_figures/01_numero_complejo_cartesiano.pdf}
```

Alternativa con SVG:
```latex
\usepackage{svg}
\includesvg[width=0.9\linewidth]{complex_phase_eeg_vector_figures/01_numero_complejo_cartesiano}
```

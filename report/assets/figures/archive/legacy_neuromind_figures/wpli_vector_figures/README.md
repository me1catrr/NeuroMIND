# Figuras vectoriales wPLI para LaTeX

Carpeta generada a partir de las infografías de referencia proporcionadas, creando ilustraciones nuevas y no recortes.

Contenido:
- 10 archivos SVG vectoriales editables.
- Versiones PDF vectoriales cuando el conversor está disponible.
- `latex_include_examples.tex` con ejemplos de inclusión.

Sugerencia LaTeX:
- Para PDF: `\includegraphics[width=0.9\linewidth]{figures/01_conectividad_fase_eeg.pdf}`
- Para SVG: usar el paquete `svg` y compilar con `--shell-escape`.
